# Document with hidden code
severity: critical
summary: The document carries hidden code, macros or a command that runs when it is opened or allowed. This is how malware gets onto phones and computers.
pretends: an invoice, a bill or an official notice
wants: to run hidden code on your device to steal your passwords or install malware
fact: Ordinary bills, tickets and letters are plain documents; they never need macros, code or a program to start.

## Steps
1. Do not open the file, and delete it from the chat.
2. If you opened it, do not click "Enable content", "Enable macros" or "Allow".
3. If you clicked one of those, disconnect the device from the internet and run a malware scan: Google Play Protect on a phone, Windows Security on a computer.
4. From another device, change the passwords you used on that device.
5. If money has left your account, call 1930 immediately and file a complaint at cybercrime.gov.in.
